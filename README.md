## Customization

To customize this portfolio for your own use:

1. Update the content in each HTML file to reflect your personal information and projects.
2. Replace the images in the `img/` directory with your own.
3. Modify the `mystyle.css` file to change the color scheme and layout as desired.
4. Update the Google Maps API key in the script tags of `MySchedule.html` and `MyForm.html` with your own key.
